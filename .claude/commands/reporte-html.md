# /reporte - Generador de Dashboard HTML de Postulaciones

Genera un reporte interactivo en HTML (`reporte_postulaciones.html`) para visualizar el embudo de tu búsqueda laboral:

- Total de postulaciones realizadas.
- Tasa de respuesta de recruiters y entrevistas conseguidas.
- Distribución de ofertas por tecnología, modalidad (remoto/híbrido) y rango salarial.
- Tabla interactiva con filtros y enlaces directos a tus CVs y cartas generadas.
