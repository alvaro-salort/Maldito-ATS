# /linkedin - Auditoría y Optimización de Perfil de LinkedIn

Analiza el perfil de LinkedIn actual del usuario y genera propuestas de mejora para aumentar la visibilidad ante reclutadores de Argentina y el exterior.

## Salidas Generadas
1. **3 variantes de Titular Profesional** optimizados con palabras clave de alto impacto.
2. **Propuesta para la sección 'Acerca de'** estructurada con propuesta de valor, logros numéricos y CTA.
3. **Optimización de experiencias laborales** destacando impacto.
4. **Lista de palabras clave (Keywords)** recomendadas para los filtros de búsqueda de RRHH.
