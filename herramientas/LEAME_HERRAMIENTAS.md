# Herramientas de Soporte - Maldito ATS

Esta carpeta contiene scripts utilitarios en Python para potenciar el flujo de búsqueda laboral:

- `consulta_salarios.py`: Consulta benchmarks salariales en ARS y USD para empresas y puestos en Argentina y LATAM.
- `comparar_ofertas.py`: Comparador multidimensional de propuestas laborales (Sueldo, SAC, bonos, prepaga, paritarias, vacaciones).
- `convertir_excel_salarios.py`: Convierte planillas de sueldos (ej. Encuesta Sysarmy / Openqube) a JSON.
- `verificar_pdf.py`: Valida que el PDF compilado por LaTeX tenga capa de texto limpia y compatible con sistemas ATS.
- `guardas_seguridad.py`: Asegura que los datos personales y de sueldo del usuario no se publiquen en repositorios públicos.
- `validar_skills.py`: Linter de sintaxis YAML para skills y comandos.
- `verificar_robots.py`: Validación de políticas de robots.txt para scraping ético.
- `control_versiones.py`: Verificador de versiones del framework.
