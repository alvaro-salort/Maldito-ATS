# Búsqueda en LinkedIn Jobs

Permite consultar vacantes publicadas en LinkedIn Jobs mediante búsqueda web estructurada o CLI.

## Parámetros Principales
- **Puesto / Rol:** Título o especialidad técnica (ej. "Backend Developer", "Data Engineer").
- **Ubicación:** País o ciudad (ej. "Argentina", "Buenos Aires", "Cordoba", "Remote", "Latin America").
- **Antigüedad:** Filtrar preferentemente ofertas de los últimos 14 días.

## Extracción de Datos
Para cada resultado relevante:
- Título del puesto
- Empresa
- Ubicación y modalidad (Remoto / Híbrido / Presencial)
- Requisitos técnicos excluyentes y deseables
- Enlace directo a la postulación
