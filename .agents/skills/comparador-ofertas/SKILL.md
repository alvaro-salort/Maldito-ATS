# Comparador y Analizador de Ofertas Laborales

Permite realizar una comparativa rigurosa y multidimensional cuando recibes una o más propuestas de empleo.

## Dimensiones de Análisis
1. **Compensación Monetaria Total Anualizada**:
   - Salario mensual base.
   - Aguinaldo (SAC) en caso de relación de dependencia local.
   - Bonos por desempeño o variable garantizado.
   - Cotización estimada de USD para contratos de exportación de servicios.
2. **Beneficios y Protección Inflacionaria**:
   - Plan de Prepaga (OSDE, Swiss Medical, etc.) y valor de mercado estimado.
   - Cláusulas de revisión salarial periódicas (trimestrales/bimestrales por IPC).
   - Días hábiles vs corridos de vacaciones / PTO.
   - Presupuesto para equipamiento (laptop, silla, monitor).
3. **Modalidad y Carga Impositiva**:
   - Relación de Dependencia vs Monotributo Tech / Factura E.
4. **Cultura, Equipo y Proyección Profesional**.
