# Optimizador de Perfil de LinkedIn

Esta habilidad analiza el perfil actual de LinkedIn del usuario y genera recomendaciones personalizadas:

## 1. Titular Profesional de Alto Impacto
- Estructura: **[Rol Actual/Deseado] | [Especialidad Técnica / Stack Principal] | [Propuesta de Valor / Logro Diferencial]**
- Ejemplo: *"Senior Backend Engineer | Go, Python, AWS | Microservicios de Alto Tráfico y Arquitecturas Distribuidas"*

## 2. Sección "Acerca de" (About)
- Párrafo 1: Propuesta de valor y tecnologías dominantes.
- Párrafo 2: Logros numéricos más relevantes y trayectoria.
- Párrafo 3: Filosofía de trabajo, liderazgo y áreas de interés.
- Párrafo 4: Llamado a la acción (contacto y disponibilidad).
