# Guía de Optimización de Perfil de LinkedIn para LATAM

---

## 1. Titular Profesional (Headline)

El titular es el campo con mayor peso en el algoritmo de búsqueda de LinkedIn Recruiter.

### Fórmula Recomendada:
> **[Rol Principal] | [3-4 Tecnologías Clave] | [Especialidad o Logro Diferencial]**

### Ejemplos Efectivos:
- *Senior Backend Engineer | Go · Python · AWS | Microservicios de Alta Disponibilidad y Fintech*
- *Fullstack Developer | React · Node.js · TypeScript · PostgreSQL | Desarrollo Web Escalable & UI/UX*
- *Data Engineer | Python · SQL · Spark · Airflow · BigQuery | Pipelines de Datos y Arquitectura Cloud*

---

## 2. Sección "Acerca de" (About)

Estructura de 4 bloques:

1. **Gancho y Propuesta de Valor:** Quién sos profesionalmente y en qué problemas te especializas.
2. **Experiencia y Logros:** Resumen de trayectoria con métricas destacadas (años de experiencia, volumen de usuarios o proyectos liderados).
3. **Stack Tecnológico:** Lista clara y legible de lenguajes, frameworks, bases de datos y herramientas cloud.
4. **Disponibilidad y Contacto:** Modalidad buscada (Remoto / Contractor / Relación de Dependencia) y email de contacto directo.
