# Plantillas de Comunicación y Networking - Maldito ATS

Esta carpeta contiene modelos estructurados para optimizar tu presencia profesional y comunicarte con reclutadores:

- `mensajes_linkedin.md`: Plantillas para mensajes de conexión y cold outreach en LinkedIn.
- `emails_seguimiento.md`: Plantillas de agradecimiento post-entrevista y consultas de seguimiento.
- `optimizacion_linkedin.md`: Guía para redactar titulares y resúmenes atractivos para recruiters.
