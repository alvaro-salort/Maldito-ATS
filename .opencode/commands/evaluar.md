# /evaluar - Clasificación y Ranking de Ofertas de Empleo

Evalúa y puntúa las vacantes encontradas en `buscador_empleos/empleos_vistos.json` o una lista de ofertas pegada por el usuario.

## Pasos de Ejecución
1. Leer las ofertas pendientes de evaluación.
2. Aplicar las compuertas de idioma y modalidad.
3. Asignar puntuación (0 a 100) en base a match técnico, seniority, compensación y reputación.
4. Generar tabla ordenada de mayor a menor compatibilidad con recomendaciones de postulación.
