# Cartas de Presentación - Maldito ATS

Esta carpeta contiene la clase y plantillas LaTeX para generar cartas de presentación personalizadas:

- `carta.cls`: Clase LaTeX con diseño elegante y profesional.
- `carta_ejemplo.tex`: Plantilla de 1 página compilable con XeLaTeX.
- `carta_<empresa>_<puesto>.tex`: Cartas redactadas a medida para cada postulación.
